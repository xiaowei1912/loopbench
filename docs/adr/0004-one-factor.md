# ADR 0004：用单因素切片做归因

## 状态

接受。

## 背景

把所有含 `lighting=dim` 的 episode 平均在一起，会把「又暗又偏相机」算进光照。那样的 delta 不能决定下一轮该补颜色还是该补手眼。

## 决定

归因只比较「恰好改了一个因素」的格子和全名义格子。`tabletop_v1` 里的 glare×camera、clutter×friction 仍然会跑、会进对照表，但不进入切片 delta。

失败模式来自 trace 的计数，不来自另一个分类器。说明文字由这些切片触发，并写明还没回来的部分。参考探针里，避障让抓取放置离开柱子，叠放仍然碰撞，文案按这个事实写。

## 后果

结论可以对应到一个杠杆：原型、地标、避障或搬运步长。交互失败需要另开实验，不能从单因素表里读出来。样本少的时候（每格 1 条）百分比很粗，界面保留 n。
